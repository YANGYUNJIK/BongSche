# 가계부 (폰 전용)

J와 Y 두 사람이 쓰는 책자형 가계부예요. 안드로이드 폰에서 쓰는 웹앱(PWA)이고, **서버 없이 폰의 브라우저에만 저장**해요(J와 Y는 따로). 사진으로 내역을 입력할 수 있어요(선택).

**설치 순서는 `docs/설치-안내서.md`를 보세요.**

## PC에서 열어 보기 (폰 화면으로 확인)
1. 이 폴더에서 터미널을 열고 아래 중 하나를 실행해요.
   - `python -m http.server 8000`  (Python이 있을 때)
   - 또는 VS Code의 "Live Server" 확장으로 `index.html` 열기
2. Chrome에서 `http://localhost:8000` 을 열어요.
3. `F12` → 왼쪽 위 휴대폰 모양 아이콘(기기 모드)을 눌러 **Pixel 7** 같은 안드로이드 크기를 고르면 폰 화면으로 보여요.
4. 처음 화면에서 J 또는 Y를 고르고, **더보기 → 예시 데이터 넣기**를 누르면 예시 기록으로 화면을 눌러 볼 수 있어요.
5. 실제로 쓰기 전에는 **더보기 → 모두 지우기**로 비워 주세요.

`index.html`을 더블클릭(file://)으로 열어도 화면은 보이지만, 오프라인 설치(PWA)는 `localhost`나 https 주소에서만 돼요.

## 폴더 구조
| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱의 뼈대 |
| `css/app.css` | 책자 느낌 스타일 (초록 천 표지, 종이, 줄 노트) |
| `js/engine.js` | **계산 엔진** — 기존 가계부와 같은 계산 로직 (화면·저장과 분리) |
| `js/store.js` | 저장소: 폰의 localStorage (J/Y 따로), 백업 파일 |
| `js/ocr.js` | 폰 안에서 사진 속 글자를 읽고 날짜·가게·금액·수입/지출로 정리 (키 필요 없음) |
| `js/photo.js` | 사진 입력 연결 (키가 있으면 AI, 없으면 폰 안에서 읽기) |
| `vendor/tesseract/` | 글자 인식 파일 (Tesseract, Apache 2.0, 약 13MB) |
| `js/demo.js` | 예시 데이터 |
| `js/app.js` | 홈·내역·예산·통계·더보기 화면과 입력 시트 |
| `js/tools.js` | 전체 검색, 붙여넣어 입력 |
| `js/settings.js` | 설정 화면 (고정 지출·할부, 예비 통장, 수입 일정, 정산 사람, 분류, 사진 분석) |
| `js/config.js`, `js/main.js` | 시작 설정과 시작 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 설치와 오프라인 |
| `docs/설치-안내서.md` | 설치·사진 분석·백업 순서 |

## 계산이 기존 앱과 같은지
`js/engine.js`는 기존 가계부의 계산 코드를 그대로 옮긴 파일이에요. 2026년 기록으로 기존 앱과 비교했을 때 1~12월의 생활비 가용액, 월 수지, 이월로 넘어가는 금액, 누적이 모두 같았어요.
