# 설치 안내서

서버가 없는 앱이에요. 기록은 **각자 폰의 브라우저(이 기기)에만** 저장되고, J와 Y는 저장 칸이 따로예요.
그래서 무료 호스팅에 올려도 **기록이 인터넷에 올라가지 않아요**(올라가는 건 앱 파일뿐이에요).

---

## 1. PC에서 먼저 확인하기

1. 압축 파일을 풀고, `gagyebu-phone` 폴더 안에서 터미널을 열어요.
2. `py -m http.server 8000` (Mac은 `python3 -m http.server 8000`)을 실행해요.
3. Chrome에서 `http://localhost:8000` → `F12` → 휴대폰 아이콘(기기 모드)으로 Pixel 크기를 고르세요.
4. J를 고르고 **더보기 → 예시 데이터 넣기**로 화면을 눌러 보세요. 확인이 끝나면 **더보기 → 모두 지우기**.

## 2. 폰에 설치하기

폰에서 앱처럼 설치하려면 앱 파일이 `https://` 주소에 있어야 해서, 무료 호스팅에 한 번 올려요.

**올릴 파일**: `gagyebu-phone` 폴더 안의 `index.html`, `manifest.webmanifest`, `sw.js`와 `css`, `js`, `icons`, **`vendor`** 폴더예요(`vendor`는 사진 읽기용이라 약 13MB예요). `README.md`와 `docs`는 안 올려도 돼요.

**Cloudflare Pages (추천, 파일 올리기)**
1. https://dash.cloudflare.com → **Workers & Pages → Create → Pages → Upload assets**.
2. 프로젝트 이름을 정하고(예: `gagyebu-k7x2q9`), `gagyebu-phone` 폴더 **안의 파일들**을 끌어다 놓고 **Deploy**.
3. 주소 `https://이름.pages.dev` 가 생겨요.

**GitHub Pages도 괜찮아요**: 기록이 파일에 들어 있지 않아서 저장소가 공개여도 안전해요. 저장소를 만들고 파일을 올린 뒤 **Settings → Pages → Branch: main / root**로 켜면 `https://아이디.github.io/저장소/` 주소가 생겨요.

**폰 Chrome에서**
1. 위 주소를 열어요 → 오른쪽 위 **⋮ → 홈 화면에 추가**(또는 **앱 설치**).
2. 홈 화면 아이콘을 눌러 J 또는 Y를 고르세요. 한 번 고르면 다음부터는 바로 열려요(바꾸려면 **더보기 → 사용자 바꾸기**).
3. 인터넷이 없어도 열려요.

> 기록이 따로 보이지 않게, 한 가지 방식(설치한 앱 **또는** Chrome 탭)으로만 쓰는 걸 권해요.

**고쳐서 다시 올릴 때**: 파일을 고쳐 같은 방법으로 다시 올리고, `sw.js` 맨 위 `VERSION` 숫자(`gagyebu-v3` → `gagyebu-v4`)를 하나 올리세요. 그래야 폰이 새 파일을 받아요. 기록은 그대로 남아요.

## 3. 사진으로 입력하기

**+ → 사진으로 입력**으로 영수증, 카드 문자 캡처, 입금 내역, 급여명세서를 찍으면 날짜·내용·금액·분류를 읽고 **수입인지 지출인지도** 골라 줘요. 읽은 내용은 미리보기로 보여 주고, 고친 뒤에 등록해요.

**기본: 폰 안에서 읽기 (키도 돈도 필요 없어요)**
- 처음 사진을 읽을 때만 글자 인식 파일(약 9MB)을 받아서 폰에 저장해요. 그 뒤로는 인터넷 없이도 돼요.
- 사진은 폰 밖으로 나가지 않아요. 한 장 읽는 데 몇 초 걸려요.
- 정확도는 **보통**이에요. 흐리거나 비뚤어지거나 반사된 사진은 글자를 잘못 읽을 수 있어요(예: GS25를 6525로, 2,689,783을 689,783으로). 그래서 미리보기에서 **날짜와 금액을 꼭 확인**하세요.
- 잘 읽히게 찍는 요령: 밝은 곳에서, 영수증을 평평하게 펴고, 가까이서, 한 장씩 찍어요.
- **화면 캡처가 가장 잘 읽혀요.** 카드 앱, 통장 내역, 월급 명세서는 폰에서 캡처(스크린샷)해서 **+ → 앨범·캡처에서 입력**으로 고르세요. 모니터 화면을 폰 카메라로 찍으면 무늬가 생겨서 잘 안 읽혀요.
- **무엇을 읽었는지 보려면** 미리보기 위쪽의 **"읽은 글자 보기"**를 누르세요. 글자가 엉뚱하면 사진 문제이고, 글자는 맞는데 칸이 틀리면 칸만 고치면 돼요.
- 읽지 못하면 "읽은 글자 보기"와 "이 글자로 붙여넣어 입력" 버튼이 나와요.
- **월급 명세서**(급여내역·세금내역·공제내역 표)는 항목마다 수입과 공제로 나눠서 한꺼번에 등록해요. 급여총액·공제총액·실수령액으로 합계를 맞춰 보고, **안 맞으면 확대 배율을 바꿔 최대 4번까지 다시 읽어요.** 그래도 안 맞으면 "합계가 안 맞아요" 경고가 나오니, 명세서와 비교해서 고치세요. 날짜는 지난달 급여일로 들어가요.

**선택: API 키로 더 정확하게**
1. https://console.anthropic.com 에서 API 키를 만들어요(결제 수단 등록이 필요해요). **월 사용 한도**를 꼭 정해 두세요(예: 5달러). 사진 한 장에 드는 돈은 아주 적어요.
2. 폰에서 **더보기 → 사진 분석**에 키(`sk-ant-…`)를 붙여 넣고 저장해요.
3. 키가 있으면 AI로 먼저 읽고, 안 될 때(인터넷 없음 등)는 자동으로 폰 안에서 읽어요. 이때는 사진이 Anthropic으로 전송돼요.
- 키는 **이 폰에만** 저장돼요. 폰을 잃어버리면 콘솔에서 그 키를 지우세요.
- 기본 모델은 `claude-sonnet-5-5`예요. 안 되면 **더보기 → 사진 분석**의 모델 칸에 쓸 수 있는 모델 이름(https://docs.claude.com 에서 확인)을 적으세요.
- 오류: "API 키가 올바르지 않아요"(키 확인), "모델 이름을 찾을 수 없어요"(모델 칸 확인), "사용 한도에 걸렸어요"(잠시 뒤 재시도·콘솔 한도 확인).

**사진 읽기가 안 될 때**
- "글자 인식 파일을 불러오지 못했어요": 호스팅에 **`vendor` 폴더**가 올라가 있는지 확인하세요(`vendor/tesseract/` 안에 `core`, `lang` 폴더가 있어야 해요). 인터넷이 켜져 있는지도 확인하세요(처음 한 번 필요해요).
- 다 올렸는데도 안 되면 앱을 완전히 닫았다 다시 여세요.

## 4. 백업과 폰 바꾸기

기록이 **이 폰에만** 있어서, 브라우저 데이터를 지우거나 앱을 삭제하면 사라져요.

- **더보기 → 백업 파일 내보내기**로 파일을 받아 두세요(2주가 지나면 홈에서 알려 줘요). 파일은 구글 드라이브나 메일로 보관하면 좋아요.
- 폰을 바꾸면 새 폰에서 앱을 설치하고 같은 사용자(J/Y)로 들어가 **더보기 → 백업 파일 가져오기**를 눌러요.
- 기존 가계부의 백업 파일도 같은 방법으로 읽을 수 있어요(2026년 기록이 들어와요).
